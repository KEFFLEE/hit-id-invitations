# מחולל הזמנות · המחלקה לעיצוב תעשייתי HIT

כלי דפדפן ליצירת הזמנות לאירועי המחלקה לעיצוב תעשייתי במכון הטכנולוגי חולון, לפי כללי המיתוג של המחלקה.

## מה יש בכלי
- פריסה לפי ההזמנות הקיימות: עמודת טקסט מיושרת לימין, לוגו עם שורת הגדרה בפינה הימנית התחתונה, קרדיט אנכי בשוליים.
- פונטים: Sunday (ExtraBold / Bold Italic) ו-Simpler Pro (Black / Bold / Regular), מוטמעים בקובץ.
- צבעי המותג: תכלת `#00ADEE`, מגנטה `#EC008C`, צהוב `#FFF200`, כחול `#2771A0`, שחור ולבן.
- פורמטים: A4 (ייצוא 300dpi), אינסטגרם 4:5, ריבוע, סטורי.
- תמונת רקע עם אזורים, התאמה, יישור, זום, סיבוב והיפוך.
- ייצוא PNG / JPG / PDF.

## שימוש
פותחים את `index.html` בדפדפן. הכלי הוא קובץ HTML יחיד, ללא התקנה.

> הגלריה המשותפת פועלת רק בגרסה שמתארחת ב-claude.ai. בהרצה מקומית או ב-GitHub Pages כל העריכה וההורדות עובדות, בלי הגלריה.
